# Upgrading to 0.20.8

## Deprecations

### Hook options

Lifecycle hook properties in route and router options are deprecated. Register global callbacks through router methods instead. A global hook runs for all matching navigations, so preserve route-specific behavior by checking the route.

```ts
// Before
const router = createRouter(routes, {
  onBeforeRouteEnter: callback,
})

// After
const router = createRouter(routes)
router.onBeforeRouteEnter(callback)
```

Route instance registration methods arrive in [0.20.11](/upgrading/0.20.11#route-callback-context); use those when upgrading beyond this release. The old options are removed in [0.21.0](/upgrading/0.21.0#hook-registration).

### Registered helper types

`RegisteredRoutes`, `RegisteredRoutesName`, `RegisteredRejectionType`, `RegisteredRouterPush`, `RegisteredRouterReplace`, and `RegisteredRouterReject` are deprecated. Infer types from your router instead.

```ts
// Before
type Navigate = RegisteredRouterPush

// After
type Navigate = typeof router.push
```

For route and rejection names, derive the type from your definitions or use router-specific types such as `RouterRouteName<typeof router>`. These deprecated helpers are removed in [0.21.0](/upgrading/0.21.0#registered-and-hook-types).
