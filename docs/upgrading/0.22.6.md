# Upgrading to 0.22.6

## Breaking changes

### Trailing slash matching

Trailing slashes in route definitions are normalized when `removeTrailingSlashes` is enabled, which is the default. Routes such as `/users` and `/users/` should no longer be used as distinct destinations under the default configuration.

If your application requires strict trailing slash matching, disable normalization:

```ts
const router = createRouter(routes, {
  removeTrailingSlashes: false,
})
```

See [Router Options](/core-concepts/router#router-options).
