# Upgrading to 0.7.2

## Breaking changes

### Names replace keys

Route definitions now expose `name` instead of `key`. A child's name is no longer joined to its parent's name. Make names unique across your router and update navigation, links, `useRoute`, and `isRoute` calls that use generated names.

For a parent named `users` and a child named `detail`, replace navigation to `users.detail` with `detail`. Alternatively, explicitly name the child `users.detail` to keep existing navigation calls.

See [route names](/core-concepts/routes#name).

### Registered names type

Rename `RegisteredRoutesKey` imports to `RegisteredRoutesName`. The latter is later deprecated in [0.20.8](/upgrading/0.20.8#registered-helper-types).

[Release changes](https://github.com/kitbagjs/router/compare/v0.7.1...v0.7.2).
