# Upgrading to 0.15.1

## Breaking changes

### Rejection method type

`RouterReject` is no longer re-exported from the package in this release. Replace an imported annotation with the type of your router's method:

```ts
// Before
type Reject = RouterReject

// After
type Reject = typeof router.reject
```

Router rejection types now follow the router's own options. See [Rejections](/advanced-concepts/rejections).

[Full release notes](https://github.com/kitbagjs/router/compare/v0.15.0...v0.15.1).
