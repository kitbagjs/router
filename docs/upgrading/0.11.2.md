# Upgrading to 0.11.2

## Breaking changes

### Rejection match names

The synthetic match rendered for a rejection no longer has the rejection type as its `name`. Remove checks such as `route.matched.name === 'NotFound'` from rejection handling. Use rejection state to identify a rejection, rather than treating it as a named route.

For current versions, use [useRejection](/advanced-concepts/rejections#get-rejection). Its export is temporarily unavailable from [0.13.3](/upgrading/0.13.3#removed-exports) through 0.22.1.

[Full release notes](https://github.com/kitbagjs/router/compare/v0.11.1...v0.11.2).
