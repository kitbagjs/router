# Upgrading to 0.13.0

## Breaking changes

### Props callback argument

Props callbacks receive the resolved route as their first argument instead of just its params. Read params from `route.params`.

```ts
// Before
const props = (params) => ({ userId: params.id })

// After
const props = (route) => ({ userId: route.params.id })
```

See [Component Props](/core-concepts/component-props).

[Full release notes](https://github.com/kitbagjs/router/compare/v0.12.0...v0.13.0).
