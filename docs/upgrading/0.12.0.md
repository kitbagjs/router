# Upgrading to 0.12.0

## Breaking changes

### Vue version

The minimum supported Vue version changes from 3.4.5 to **3.5.0**. Update Vue before installing this release.

### Hook helper types

`RouteHookAbort` is no longer exported. Infer the type of the callback's `abort` argument, or use `() => void` for an explicit annotation.

`BeforeRouteHookResponse`, `AfterRouteHookResponse`, and `RouteHookResponse` no longer take a routes generic argument. Remove that argument from explicit annotations.

See [Hooks](/advanced-concepts/hooks).

[Full release notes](https://github.com/kitbagjs/router/compare/v0.11.4...v0.12.0).
