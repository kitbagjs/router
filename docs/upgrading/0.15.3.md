# Upgrading to 0.15.3

## Breaking changes

### Component enter hook

The component-level `onAfterRouteEnter` export is removed. Register route-entry work on the route or router. For work that belongs to mounting a component, use Vue's `onMounted`.

```ts
// Before
import { onAfterRouteEnter } from '@kitbag/router'
onAfterRouteEnter(callback)

// After: route navigation callback
router.onAfterRouteEnter(callback)
```

A global hook is not restricted to one component's route. Check the destination when needed. Route instance methods become available in [0.20.11](/upgrading/0.20.11#route-callback-context). See [component hooks](/advanced-concepts/hooks#component).
