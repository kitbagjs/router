# Upgrading to 0.28.0

## Breaking changes

### Removed view options

The `component` and `components` options and the second `createRoute` props argument are removed. These were deprecated in [0.25.0](/upgrading/0.25.0#view-options).

Use one `addView` call per component. Put props in that view's `props` option, and supply `name` for named views.

```ts
const user = createRoute({
  name: 'user',
  path: '/users/[id]',
})
  .addView(UserPage, {
    props: (route) => ({ userId: route.params.id }),
  })
```

Follow the [before/after migration](/upgrading/0.25.0#view-options) for both single and named views. See [Views](/core-concepts/routes#views) for current options.

### View props types

`CreateRouteProps`, `PropsGetter`, `RouterViewPropsGetter`, and `PropsCallbackContext` are removed with the legacy view options. Infer the props callback through `addView`, or use its public `AddViewPropsGetter` and `AddViewPropsCallbackContext` types where an annotation is needed.

[Full release notes](https://github.com/kitbagjs/router/compare/v0.27.0...v0.28.0).
