# Upgrading to 0.24.2

## Breaking changes

### Internal helper exports

The package no longer exports `combineRoutes`, `getHooks`, `combineHooks`, or the `isWithComponent`, `isWithComponents`, `isWithComponentProps`, `isWithComponentPropsRecord`, and `isWithParent` helpers.

Use `createRoute` with a `parent` to compose routes, and register hooks through route or router methods. Keep application-specific checks on your own configuration rather than using internal option guards.

Hook runner and registration internals are also removed: `InternalRouteHooks`, `ExternalRouteHooks`, `HookTiming`, `ComponentHook`, `ComponentHookRegistration`, `AddComponentHook`, `AddGlobalHooks`, `BeforeHookResponse`, `AfterHookResponse`, `BeforeHookRunner`, `AfterHookRunner`, `RejectionHookRunner`, `ErrorHookRunner`, and `ErrorHookRunnerContext`.

For application callbacks, use the lifecycle-specific public hook types such as `BeforeEnterHook` and `BeforeEnterHookContext`, or let the registration method infer the arguments. See [Hooks](/advanced-concepts/hooks).
