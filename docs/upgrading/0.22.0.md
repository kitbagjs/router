# Upgrading to 0.22.0

## Breaking changes

### URL string types

The string URL type `Url` is renamed to `UrlString`, and its guard `isUrl` becomes `isUrlString`. Update imports and explicit type annotations.

```ts
// Before
import type { Url } from '@kitbag/router'

// After
import type { UrlString } from '@kitbag/router'
```

The name `Url` is subsequently used for the object returned by `createUrl` in [0.22.1](/upgrading/0.22.1#route-url-methods). See [Navigation](/core-concepts/navigation).

### URL conversion helper

Rename `asUrl` to `asUrlString`. Its string-normalization behavior is unchanged.

[Full release notes](https://github.com/kitbagjs/router/compare/v0.21.0...v0.22.0).
