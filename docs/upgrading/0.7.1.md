# Upgrading to 0.7.1

## Breaking changes

### Inherited meta

A child route now merges its parent's meta instead of replacing it. Review child routes that relied on a missing parent value: explicitly override that value on the child where appropriate. See [Route Meta](/advanced-concepts/route-meta).

### Match record types

`CreateRouteOptionsMatched` is no longer exported. Infer a match record from your route, for example `typeof route.matched`, instead of importing the implementation alias. Created route definitions later lose `matched` in [0.25.0](/upgrading/0.25.0#route-and-match-types).

[Full release notes](https://github.com/kitbagjs/router/compare/v0.7.0...v0.7.1).
