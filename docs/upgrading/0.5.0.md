# Upgrading to 0.5.0

## Breaking changes

### Current route types

The current route is now a union of the registered routes. Use `isRoute` or `useRoute(name)` to narrow it before reading params that only exist on one route. Explicit `Route` type arguments also change; prefer the inferred type of a definition over manually filling its generics.

The exported `UseRouteOptions` type is removed. Pass the options object directly, for example `useRoute('users', { exact: true })`, and let TypeScript infer it.

See [Route Narrowing](/advanced-concepts/route-narrowing).

[Full release notes](https://github.com/kitbagjs/router/compare/v0.4.2...v0.5.0).
