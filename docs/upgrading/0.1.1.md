# Upgrading to 0.1.1

## Breaking changes

### Route components

Route components now use Vue's `Component` type. Replace a raw async component loader with `defineAsyncComponent` and replace imports of the removed `RouteComponent` type with Vue's `Component`.

```ts
// Before
const component = () => import('./HomePage.vue')

// After
const component = defineAsyncComponent(() => import('./HomePage.vue'))
```

Import `defineAsyncComponent` from `vue`. See [Prefetching Components](/advanced-concepts/prefetching#prefetching-components).

[Release changes](https://github.com/kitbagjs/router/compare/v0.1.0...v0.1.1).
