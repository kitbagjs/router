# Upgrading to 0.11.0

## Breaking changes

### Router startup

Creating a router no longer starts its initial navigation. Installing it with `app.use(router)` starts it automatically. For tests, server rendering, or other usage without installation, call `await router.start()` before reading the initial route.

Replace the removed `router.initialized` promise:

```ts
// Before
await router.initialized

// After
await router.start()
```

See [Start](/core-concepts/router#start).

[Full release notes](https://github.com/kitbagjs/router/compare/v0.10.2...v0.11.0).
