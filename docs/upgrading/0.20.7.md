# Upgrading to 0.20.7

## Breaking changes

### Router helper types

`RegisteredRouteMap`, `RegisteredRouterRoute`, and `RegisteredRoutesName` are no longer exported. Infer route types from your router instead, using `typeof router.route` or `typeof router.route.name`. `RegisteredRoutesName` is exported again, but deprecated, in [0.20.8](/upgrading/0.20.8#registered-helper-types).

`AddBeforeRouteHook` and `AddAfterRouteHook` are removed. Infer registration method types from the router, for example `typeof router.onBeforeRouteEnter`.

For routers created with `global: false`, use `createRouterAssets(router)` to get components, composables, and component hooks tied to that router. See [Type Safety](/core-concepts/type-safety).

[Release changes](https://github.com/kitbagjs/router/compare/v0.20.6...v0.20.7).
