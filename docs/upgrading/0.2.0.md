# Upgrading to 0.2.0

## Breaking changes

### Param syntax

Replace colon params with square brackets in path and query templates. Optional params put `?` inside the opening bracket.

```ts
// Before
const path = '/users/:id'
const query = 'page=:?page'

// After
const path = '/users/[id]'
const query = 'page=[?page]'
```

See [Params](/core-concepts/params).

[Full release notes](https://github.com/kitbagjs/router/compare/v0.1.1...v0.2.0).
