# Upgrading to 0.31.0

## Breaking changes

### Loader definition type

The exported `RouteLoader` type is removed. Use `Loader` for reusable loader definitions, or infer the type from `createLoader`.

## Deprecations

### Component loader data

Reading `route.data` from a component is deprecated. Use `useLoader` with the corresponding definition from `route.loaders` for reactive data, loading state, and errors.

```ts
// Before
const route = useRoute('user')
const user = await route.data

// After
const route = useRoute('user')
const { data: user } = await useLoader(route.loaders.default)
```

For named loaders, replace `route.data.user` with `useLoader(route.loaders.user)`. The returned `data` is a ref; read `.value` in script. Omit `await` when the component should handle loading state itself.

This release only deprecates component reads. Callback reads remain supported in 0.31.0 and 0.32.0; their later migration is tracked under [Unreleased](/upgrading/unreleased).

See [useLoader](/composables/useLoader) and [RouterSuspense](/components/router-suspense).
