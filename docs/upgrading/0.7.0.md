# Upgrading to 0.7.0

## Breaking changes

### Disabled routes

The `disabled` route option is removed. For a parent used only to organize children, omit its name and register the children you want to navigate to. See [routes without names](/core-concepts/routes#routes-without-names).

### Route meta registration

Replace declaration merging of the `RouteMeta` interface with a `routeMeta` property on `Register`.

```ts
// Before
declare module '@kitbag/router' {
  interface RouteMeta {
    requiresAuth?: boolean
  }
}

// After
declare module '@kitbag/router' {
  interface Register {
    routeMeta: { requiresAuth?: boolean }
  }
}
```

See [Route Meta](/advanced-concepts/route-meta).

### Route helper types

`CreateRouteOptionsWithMeta` and `RegisteredRouterState` are removed. Infer a route's match and state types from the route instead of these aliases.

[Full release notes](https://github.com/kitbagjs/router/compare/v0.6.0...v0.7.0).
