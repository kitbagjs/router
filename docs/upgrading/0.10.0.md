# Upgrading to 0.10.0

## Breaking changes

### URL part values

The objects returned by `path`, `query`, and `host` now store their template string in `value`. Replace reads of `.path`, `.query`, or `.host` on those objects with `.value`.

```ts
const userPath = path('/users/[id]', { id: Number })

// Before
userPath.path

// After
userPath.value
```

These helpers are later replaced by `withParams` in [0.17.3](/upgrading/0.17.3). Route definitions change their URL representation again in [0.22.1](/upgrading/0.22.1#route-url-methods).

[Full release notes](https://github.com/kitbagjs/router/compare/v0.9.0...v0.10.0).
