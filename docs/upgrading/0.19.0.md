# Upgrading to 0.19.0

## Breaking changes

### Param collection arguments

Pass a single array to `arrayOf`, `tupleOf`, and `unionOf` instead of separate arguments.

```ts
// Before
arrayOf(Number, Boolean)
tupleOf(String, Number)
unionOf('small', 'large')

// After
arrayOf([Number, Boolean])
tupleOf([String, Number])
unionOf(['small', 'large'])
```

`arrayOf` and `tupleOf` also accept a second options argument for a custom separator. See [Arrays](/core-concepts/params#arrays), [Tuples](/core-concepts/params#tuples), and [Unions](/core-concepts/params#unions).

[Release changes](https://github.com/kitbagjs/router/compare/v0.18.2...v0.19.0).
