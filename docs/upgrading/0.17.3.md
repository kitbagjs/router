# Upgrading to 0.17.3

## Deprecations

### URL template helpers

Replace the `path`, `query`, and `host` helpers with `withParams`. The arguments remain the same.

```ts
// Before
import { path } from '@kitbag/router'
const userPath = path('/users/[id]', { id: Number })

// After
import { withParams } from '@kitbag/router'
const userPath = withParams('/users/[id]', { id: Number })
```

The aliases are removed in [0.21.0](/upgrading/0.21.0#url-template-helpers). See [Param Types](/core-concepts/params#param-types).

[Release changes](https://github.com/kitbagjs/router/compare/v0.17.2...v0.17.3).
