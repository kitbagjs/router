# Upgrading to 0.14.0

## Breaking changes

### Resolving routes

`router.find` is removed in this release; use `router.resolve` for either a name or a URL. `router.resolve` now returns a resolved route or `undefined` instead of a URL string. Check the result and use `.href` when you need a string.

```ts
// Before
const href = router.resolve('home')

// After
const resolved = router.resolve('home')
const href = resolved?.href
```

The URL overload moves back to `router.find` in [0.14.1](/upgrading/0.14.1). See [Router Methods](/core-concepts/router#router-methods) for current usage.

[Release changes](https://github.com/kitbagjs/router/compare/v0.13.4...v0.14.0).
