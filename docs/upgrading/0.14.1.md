# Upgrading to 0.14.1

## Breaking changes

### URL lookup

Use `router.find(url)` for URL lookup. `router.resolve` now only accepts route names and returns a resolved route without `undefined`. This revises the combined API from [0.14.0](/upgrading/0.14.0).

```ts
// Before
const route = router.resolve('/users/123')

// After
const route = router.find('/users/123')
```

Continue checking the result of `find`, since a URL may not match. See [Find](/core-concepts/router#find) and [Resolve](/core-concepts/router#resolve).

[Full release notes](https://github.com/kitbagjs/router/compare/v0.14.0...v0.14.1).
