# Upgrading to 0.16.0

## Breaking changes

### Route props

Move the `props` option out of the route options and into the second argument to `createRoute`. Although the old option is marked deprecated, its type is `never` and it can no longer be used.

```ts
// Before
const user = createRoute({
  name: 'user',
  path: '/users/[id]',
  component: UserPage,
  props: (route) => ({ userId: route.params.id }),
})

// After
const user = createRoute({
  name: 'user',
  path: '/users/[id]',
  component: UserPage,
}, (route) => ({ userId: route.params.id }))
```

For named views, the second argument is an object of props getters keyed by view name. This syntax is later deprecated in [0.25.0](/upgrading/0.25.0) and removed in [0.28.0](/upgrading/0.28.0). See [Component Props](/core-concepts/component-props) for current usage.

[Release changes](https://github.com/kitbagjs/router/compare/v0.15.3...v0.16.0).
